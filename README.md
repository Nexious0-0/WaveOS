# WaveOS

WaveOS is a lightweight browser-based desktop environment prototype with an ocean-inspired visual style.

## Features

- Welcome page with a link into the desktop experience
- Interactive desktop layout with app icons and windows
- Start menu, taskbar, clock, window controls, and desktop context menu
- Devlogs page documenting the project progress
- Responsive layouts for desktop and smaller screens

## Project Structure

```text
WaveOS/
├── index.html       # Welcome page
├── desktop.html     # Interactive desktop experience
├── devlogs.html     # Project development notes
├── Bubble Browser   # Browser prototype file
└── App icons/       # Desktop app icon assets
```

## Run Locally

The project is made with plain HTML, CSS, and JavaScript, so no build step is required.

From the repository root, start a local server:

```bash
cd WaveOS
python3 -m http.server 8000
```

Then open [http://localhost:8000/index.html](http://localhost:8000/index.html) in a browser.

## Pages

- `index.html` - WaveOS welcome page
- `desktop.html` - OS-style desktop interface
- `devlogs.html` - WaveOS development log
